# Tecnologías Utilizadas en Logikia

## Framework Principal

- **Astro:** Framework de sitios web estáticos que permite construir sitios rápidos con una excelente experiencia de desarrollo.

## Documentación y Contenido

- **Starlight:** Integración de Astro para la creación de sitios de documentación. Se utiliza para las secciones de "blog" e "insights".
- **MDX:** Permite el uso de componentes de React/Vue/Svelte dentro de archivos Markdown.

## Estilos y UI

- **Tailwind CSS:** Framework de CSS "utility-first" para un diseño rápido y personalizado.
- **Preline UI:** Biblioteca de componentes de interfaz de usuario de código abierto construida sobre Tailwind CSS.

## Herramientas de Desarrollo y Build

- **Vite:** Herramienta de "build" y servidor de desarrollo que proporciona un feedback rápido durante el desarrollo.
- **TypeScript:** Añade tipado estático a JavaScript para mejorar la robustez y mantenibilidad del código.
- **ESLint y Prettier:** Para el "linting" y formateo del código, asegurando un estilo de código consistente.

## SEO y Optimización

- **@astrojs/sitemap:** Genera automáticamente un sitemap para mejorar el SEO.
- **astro-compressor:** Comprime los archivos HTML, CSS y JS para mejorar el rendimiento.
- **Sharp:** Biblioteca de procesamiento de imágenes para optimizar las imágenes.

## Animaciones y Experiencia de Usuario

- **GSAP (GreenSock Animation Platform):** Biblioteca de animación para crear animaciones de alto rendimiento.
- **Lenis:** Proporciona un efecto de "smooth scrolling" para mejorar la experiencia de usuario.
